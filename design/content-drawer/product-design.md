# 右侧内容面板抽屉动画设计

日期：2026-10-13。状态：用户已明确“UI 交互审核通过，可以继续”。入口为 [index.html](index.html)，调研依据为 [research.md](research.md)。本次调整内容面板的收放方式，保留既有业务布局与原生标题栏。批准是正式实施依据，不代表实现或产品验收通过。

## 固定形态向右进出

右侧展开完整宽度记为 W，动画时可见占位记为 V。内层始终宽 W，以右边缘为锚点，向右平移 W−V。外层裁切屏幕外的部分，向对话区释放或收回占位。正文原有多行保持相同行数、行宽和行高，字段、卡片、图标、工具按钮、Tab 条及编辑器保持相对位置与尺寸。长标题保留原有渐隐，不因动画新增换行或改变紧凑模式。

不缩放、拉伸或整栏淡出。动画可以裁掉部分字形，这是越过窗口边缘的遮挡，不是文字变窄或重排。左侧继续以 V−W 向左平移，两侧使用相同曲线和时长，方向镜像。

## 收起与展开

点击内容标题栏现有收放按钮时向右收起，420ms 后完全离开可见区域。对话标题栏的恢复入口在开始收起时即可用；展开期间保留可见切换入口，允许再次点击换向。从隐藏状态展开时先确定最终完整宽度，再从右侧进入，时长 560ms。正常手动分栏宽度继续记忆，终态由原分栏约束投影。

快速点击从当前可见位置继续，固定宽度沿用到动作结束，不能跳回起点。左右同时显隐仍由原协调器一次性合成布局。减少动态效果模式直接切换到终态，不出现挤压中间帧。

## 状态与焦点

收放不重建 ContentTabs、29 类业务面板或 MarkdownEditor；保持草稿、编辑器选区和撤销记录、Tab 活动项、Tab 顺序及滚动位置。收起完成后在不可见且 inert 的容器中保留内容实例。实际关闭 Tab、切换账户或目录等原有生命周期继续执行。

动画和隐藏期间右抽屉不可点击、不可进入 Tab 焦点序。开始收起时若焦点在其中，移到可见恢复入口；展开完成时可恢复仍有效的原目标，失效时回内容标题栏收放按钮。用户已经主动把焦点移到其他地方时不抢焦点。临时非模态菜单、Tooltip 和拖拽预览结束或关闭，业务 Dialog 的输入和保存门控保留。

## 窗口调整与全屏

动作外调整窗口或分栏可正常重新排版。动作内固定完整宽度，额外 resize 只改变可见裁切边界，完成后一次性按新尺寸校正。900px 断点在动作结束后落实，避免半途隐藏旧 pane 或把内层改为窄宽。

窄窗口中右内容使用工作区全宽，覆盖对话，从右侧整块进出；收起后返回对话。窄屏尺寸不覆盖桌面偏好。全屏内容收起同样锁定开始时的完整宽度，保留原返回对话行为；中途全屏或 Tab 激活命令以最新意图为准，在统一协调器中衔接当前几何。

Windows / macOS 原生窗控保持原位置和安全区，不跟随抽屉移动。HTML 中的窗控轮廓仅用于显示固定边界，原生标题栏命中须在各实际目标系统验证。

## HTML 审核方式

默认展示玄墨主题、1280px 工作区、500px 内容面板。可切宣纸主题、1024/900/700px 工作区、不同右栏宽度，查看正文和表单示意。点击右栏现有收放图标收起，点击对话标题栏恢复图标展开；外部切换入口可快速反向。左侧收放用于比较同形抽屉的动作。

外部慢速预览与定格滑条便于查看任意中间帧；读数展示完整宽度和可见占位。HTML 提供静止时进入全屏以及全屏态收起；动作中全屏替换命令、真实业务 Tab 激活、Portal 与编辑器生命周期在正式组件阶段验证。所有审核控件位于工作区之外，合成文字、窗控轮廓和数据不进入安装版。HTML 不连接接口，不创建作品或发送对话。

## 验收条件

| 编号 | 条件 | 证据要求 |
| --- | --- | --- |
| CD 01 | 收放每帧完整宽度及文字行数不变，布局相对尺寸不变，只平移和裁切 | 双主题、正文/表单/长标题，逐帧几何与行框 |
| CD 02 | 向右进出，与左导航同曲线和时长 | 两侧中间帧与终态；无缩放/过冲 |
| CD 03 | 快速反向、同时收放、全屏打断无跳变，最新意图落位 | 隔离真实组件多命令时序和真实操作 |
| CD 04 | 隐藏/动画不可聚焦，恢复入口可达，临时菜单关闭，业务弹窗保持 | 键盘、原生菜单、Portal、失效焦点与主动转移 |
| CD 05 | Tab、真实编辑器草稿/选区/撤销/滚动保持 | 实例标识与实际 Monaco 编辑验证 |
| CD 06 | 动作中 resize/跨900px断点不挤压；终态合法且不污染偏好 | 900/899px两侧及窄宽双向；保存/恢复/重开 |
| CD 07 | 原分栏拖动、减少动态效果、离线启动、标题栏安全区不回归 | 现有相关用例、全量回归与实际目标系统 |

设计验证只证明 HTML 的几何和交互，不能替代正式组件、原生系统或全部业务验收。
