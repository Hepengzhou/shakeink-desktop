阶段：预览验证用例；以下为待执行用例，不是已通过结果。仅验证本目录原型，不验证产品 React、持久化、供应商请求或 Electron。

| ID | 操作 / 断言 | 证据 |
| --- | --- | --- |
| PV01 | `file://` 离线打开；零 pageerror、资源读取失败、HTTP(S) 请求；所有静态素材可读 | 请求记录 / 检查 JSON |
| PV02 | 宣纸、玄墨各截图；背景、Logo、主次入口和 composer 切换一致；正文与辅助文案对比度≥4.5 | 截图 / 实测对比值 |
| PV03 | 两主题1000、560、420、320px 面板宽度：作品占组整行，其他三入口等宽同排；文字完整、输入区工具可达；标题和按钮水平居中；无横向溢出 | 矩形坐标 |
| PV04 | 常规高760及短高520/420（含320×420）：输入区位于面板底部，欢迎区可滚动到所有动作，无重叠 / 裁切 | 坐标 / 短窗截图 |

| PV06 | 真实 Logo 首帧来自两套源 SVG；全部帧炉身区域像素相同，烟部至少部分像素变化；精灵无越界 | 资产像素与SHA记录 |
