### T-P2-01：宽度矩阵加入规格承诺的 320px

- 依据：`product-design.md:29` 承诺“≥320px仍保持三次入口同排，按钮文字不截断”，但 `test-cases.md:9`（PV03）只列 1000、560、420px；PV11 的“等效窄空间”没有明确覆盖这个边界。
- 要求：PV03 明确加入 320px 的两主题检查，断言三次入口文字完整、输入区工具可达、无横向溢出。短高检查至少覆盖一次 320×420 的最紧组合。可以复用同一矩形/截图脚本，无需扩大到产品屏幕测试。
- 复核：`test-cases.md:9–10` 的 PV03/PV04 已加入两主题 320px、文字/工具可达、320×420 短窗组合。已关闭。

### T-P2-02：动画用例覆盖按钮整面 hover 与循环接缝

- 依据：`product-design.md:61` 规定“鼠标进入图标或所属按钮时播放”及 keyboard focus；`:65–69` 规定循环帧。`test-cases.md:11`（PV05）仅逐个 hover 图标，不能检出按钮仅图标热点有反应或鼠标移出错误覆盖仍存在 focus-visible 的情况；也未检查循环回首帧的视觉接缝。
- 要求：补充 hover 按钮文字/空白处同样驱动本按钮图标；hover 与 focus-visible 同时存在时，移除一种仍继续播放，二者都解除后回0；保持 hover 至少一个完整周期，观察最后帧→首帧没有明显跳切。Logo 和至少一款按钮图标须有真实浏览器循环截图/帧序列证据，其余可以逐帧资产检查。减少动态仍应优先阻止所有触发。
- 复核：`test-cases.md:11` 的 PV05 已完整补入整面 hover、hover/focus-visible 叠加、Logo 与书册完整周期及接缝；`:14` 的 PV08 明确系统 reduce 优先级。已关闭。
