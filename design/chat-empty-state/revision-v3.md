# AI 对话首屏 v3 · 灵感展开

日期：2026-10-12。阶段：研究与设计方案，等待本轮HTML审核。用户最新要求覆盖v2的灰阶统一图标、小按钮和单行主入口；原v2保存在 `archive-v2/`。仅设计目录修改，正式组件仍遵循真实ChatPanel/composer复用边界。

## 1. 参考与观察

### 卡片图文及动效

实际浏览 [Manus 官方公开首页](https://manus.im/?index=1)，点击公开「设计」入口后，观察到两列卡片：文案位于左侧，右侧叠放两张主题图。所见卡片约366×92px，右侧图层宽102px；页面DOM中的hover样式显示，两图分别上移5/7px、横向错位并小幅旋转，200ms ease-out。此处依据公开页面截图及DOM样式，不声称进入登录工作台或实际录制hover视频。

本稿借鉴「左侧清晰动作＋右侧叠放图像＋局部悬停展开」的原则；原创图像、布局层级、写作入口与主题色属于玄印。作品卡用笔/手稿，角色卡用人物设定，世界观用地图，场景用山景取景图；不复制参考站图片、文字和品牌。

### 烟气运动

已查看 APS 的[Spinning Smoke真实实验照片](https://gfm.aps.org/meetings/dfd-2018/5b9c4e1bb8ac3105e5ac91dc)：近源烟束细而稳定，中上段出现局部卷曲，顶部散为细丝。另实际播放CU Boulder的[双香烟实验影片](https://www.flowvis.org/2014/02/13/two-incense-smoke-streams-interact-viewed-sideways-and-slowed-by-30/)，在00:00与00:16读取画面：细直烟束保持入流，局部卷环在不同位置形成，末端逐渐散成细丝，并非整条同步摇摆。[拍摄报告](https://flowvis.org/media/2014/2014GetWet/Reports/Alex_Unger.pdf)描述局部弯曲增长为旋涡，且影片画面旋转过90°，画面向左实际对应上升。这里只声明播放和两时点观察，没有声称完整逐帧分析全部影片；照片观察、报告事实与设计推论分别记录。

v2以同一phase驱动整段烟，垂直抬高后又落回，容易显得像弹性带。本轮设计推论是用2–3个错时出现的局部波包替换整体往返：固定炉口，波包仅向上移动，经过顶部后减弱，根部形变最小。周期末波包消退后衔接原轮廓，不倒放。幅度约为v2的40–60%，不再以更大幅度作为自然感指标。它仍是保留品牌形状的风格化烟动画，不宣称物理流体仿真。

## 2. 布局与视觉方案

中央欢迎区与底部输入区统一使用最大800px、同一水平留白变量，左右边缘严格对齐。44px空顶栏保留，composer为独立不收缩底部槽；欢迎内容放在可滚动剩余空间中。

桌面布局共三排：

1. 创建作品 / 新角色：两等列，尺寸完全相同，约108–120px高。
2. 新世界观 / 新场景：两等列，约88–96px高，小于上一排；同宽但面积更小。
3. 仙侠 / 历史 / 科幻：三等列，全幅图卡，约96–108px高，始终位于全部创作入口下方。

宽度不足480px时创作入口与主题入口均改为单列，作品/角色保留相同较大高度，世界/场景保留较小高度；所有入口依序滚动可达。不能缩小到旧v2按钮尺寸来强塞首屏。短窗不遮挡composer、不隐藏卡片，只收紧欢迎头部空间并滚动。

四个创作卡片使用相同背景/边框/hover表面；不包含底部三张全幅主题图卡。每张创作卡左边的图标、标题、副标题左边缘对齐，右边是专属装饰插画。作品/角色包含一句短副标题；其他卡片不增加冗余段落。创建作品无右侧箭头，图标为精致的笔尖/书写符号。

图标采用「单图单色，四图不同色」：作品琥珀、角色紫、世界青绿、场景蓝；只用实心和透明负形，不使用多色插画代替图标。右侧插画允许同色系多色，以形状层次而非厚重3D表现。底部主题图完整覆盖卡片，标题位于左下，采用足以保证对比度的暗色局部遮罩；图上不生成文字。

Logo玄墨从v2的#d0d0d0降为中灰（目标#8d8984）；宣纸从冷灰#b8b8b8改为贴近纸色的暖黄灰（目标#b6a47c）。最终色值记录在manifest，首帧保留真实品牌路径。中央Logo约88px，标题26px/普通字重，整体减少冗余文案。

## 3. 动效与资产技术方案

- Logo：仍用本应用原SVG为唯一形状来源，炉身及炉口固定。烟轮廓分高度相位，弯曲向上传播并减弱，避免全部控制点同时左右拉伸；有限长周期平滑闭合。实际周期/帧率由manifest与HTML data属性一致声明。
- 四个小图标：原生SVG、每枚只一种实色，保留轻微局部悬停帧变化。
- 四个右侧插画：独立透明精灵帧，局部纸张/构件分层舒展；hover整个卡片或keyboard focus-visible时，图标与右图一起触发。离开时复位，其他卡片保持静止。
- 三张主题图：分别通过内置imagegen生成真实位图，不使用渐变或SVG占位冒充。复制到项目本地 `assets/theme-{xianxia,history,scifi}-v3.png`，记录提示词、尺寸及哈希。HTML以object-fit:cover铺满，hover作轻微图像推近；它们不声称是生成视频帧。
- 所有动态尊重系统/预览减少动态、页面失焦/隐藏与弹窗暂停。隐藏分支如不能真实触发则明确未验证。离线file预览，不启动HTTP服务、不上传品牌图或凭据、不连接产品数据。

## 4. 动作契约

四创作入口继续保留v2真实业务意图和只展示说明的原型边界。无作品时，世界/角色/场景先选作品；实际产品复用现有实体创建流程。

仙侠/历史/科幻代表创建作品时的题材起点。HTML点击仅打开带对应题材名称的流程说明，不创建作品、不修改现有草稿、不自动发送。正式接入时打开同一创建作品向导并预选题材，已有草稿沿用原确认流程；不能把题材卡当作额外假作品或模型。

## 5. 交付及验证顺序

研究/方案 → 独立方案审核 → [v3验证用例](./test-cases-v3.md)及独立审核 → 原型与资产 → 独立代码审核及本机浏览器验证 → 用户审核HTML。

v1、v2及其证据独立归档，不进入v3扫描/哈希；v3结果须绑定实际运行源码与素材。所有图像审美和烟气自然度都需目视，不能只凭像素差或几何断言判定。
