# AI 对话首屏 v2 · 灰阶与呼吸

日期：2026-10-12。依据：用户在v1审核后明确要求 Logo亮灰、烟气幅度增大、按钮统一背景、图标单色面性，并参考Manus 2.0的首屏质感；这些新要求覆盖v1相应色彩设计。原稿保存在 `archive-v1/`，本轮仍只修改HTML设计稿。

## 调研补充与设计方向

提供的 Manus `/app` 在未登录会话中重定向到登录页，未进入登录后的工作台，也不把登录页当作首屏证据。转而查看其[官方公开首页](https://manus.im/?index=1)的输入起点与创作入口，以及[官方2.0介绍](https://manus.im/en/blog/introducing-manus-2-0)。参考范围限定为低色彩噪声、细边框、克制的字号/字重、圆角输入容器与较充足留白；不复制品牌、页面布局、文案或图标。

设计名称：**灰阶与呼吸**。继续采用真实玄印香炉轮廓；让动态烟形承担识别度，以统一材质、文字比例和疏密节奏营造现代桌面质感。

## 技术与视觉方案

- Logo：双主题均为R=G=B灰阶，玄墨用亮灰，宣纸用稍收敛的亮灰以保留辨识；保留原SVG炉身与烟路径。扩展透明画布给烟形留出空间，烟的水平幅度约为v1的5–6倍，加入垂直舒展，连续弯曲原烟形，炉身不动；最终采用原轮廓的局部变形，不叠加额外烟迹。64离散帧，16fps，4秒；禁止整体摇晃Logo。
- 四个入口：统一背景、边框、hover背景和hover边框；主入口仅靠全行宽度、字号、空间获得优先级。次入口改为更轻、更低的横排按钮，减少大块卡片感。
- 图标：重新绘制四枚真正单色实心符号，不把多色插画简单灰度化；以透明负形表达书页/星球/人物/山峦。保留各自悬停局部帧动画，单一不透明色，抗锯齿边缘允许alpha。
- 排版：标题从口号感的粗体改为较轻的现代字重，更宽松的字距与上下间距；按钮组最大宽480px。主/次按钮约74/58px，图标约28/22px。Logo画布128px，实际炉身轮廓与整体空白重新平衡。
- 输入区：始终在底部；收窄宽屏上限至800px，圆角20px，以细描边和表面明度承载质感。保持现有模型/模式/引用/作品入口，移除大面积朱砂强调；原主题语义不被替换。
- 原宣纸/玄墨基础色沿用，新增欢迎区灰阶与统一表面局部token。无渐变背景、玻璃效果或厚阴影。焦点保留清晰可见状态。

## 修订验证用例（在v1用例之上）

1. 双主题四个按钮的普通/hover computed background 与border必须完全相同；不能遗留旧朱砂/青绿/紫/金底。
2. 每枚按钮SVG只有一种实色；PNG不透明像素的RGB为相同单色，透明负形确实存在。两主题Logo RGB通道相等，首帧轮廓来自原路径（只允许灰度换色和统一画布变换）。
3. Logo所有帧炉身固定区像素不变；烟最大位移明显大于v1，记录源坐标幅度和栅格烟覆盖区变化，人工看动态周期及联系图；增加画布后不裁切烟形。
4. 重跑既有PV01–PV12中实际受影响的完整预览验证，适配灰阶首帧比较、16fps Logo与新尺寸。保留键鼠切换、非负帧、reduce、短窗、模态和离线检查；真实hidden不能触发继续明确未执行。
5. 最终图纸、文档和运行证据一起更新，旧v1结果不得当作v2通过；独立子代理先审核方案/新增用例，再做代码审核。
