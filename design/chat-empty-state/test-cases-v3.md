# AI 对话首屏 v3.4 · 预览验证用例

依据：[v3研究与方案](./revision-v3.md)。仅HTML设计验证，不是产品业务/Electron/安装包验收。

| ID | 操作与验收 |
| --- | --- |
| V3-01 离线资产 | file协议加载两主题Logo/四静态彩色图标/四右侧插画/三张本地主题图及源分类与401条模板；无HTTP请求、脚本错误或失败资源。模板数据与真实源码逐项一致且有来源哈希。 |
| V3-02 布局层级 | 两主题1000/560/480/420/320px；按钮组与composer左右边缘误差≤1px；四功能卡同宽同高；桌面前两排各两列，题材三列且在最下面；<480px单列。无横向溢出。 |
| V3-03 大卡片构图 | 四卡图标与文字同左边缘，副标题完整且不被右图遮挡；作品无箭头且用笔图标。玄墨右图grayscale(1) brightness(.62)，宣纸右图grayscale(1) sepia(.5) brightness(.62)，均opacity .5；0..12播放帧共用滤镜。小图标、Logo及整卡不受滤镜影响。纸色0/12与墨色截图目视，四卡同表面；题材全幅图覆盖、标题不截断。 |
| V3-04 色彩资产 | 每枚小图标SVG只一种实色，所有帧PNG不透明RGB同一颜色；四图标色值各异。Logo ink亮度低于v2，paper为暖黄灰。右侧多色插画和主题图不纳入单色断言。 |
| V3-05 品牌及自然烟 | 规范化换色/viewBox后首帧与原品牌一致；全部帧炉身/炉口固定；局部烟形变化、上行相位、循环首尾连续，无透明画布裁剪。实际周期联系图/动态查看判断是否仍有全段同步左右摆动；记录可见改善与局限，不用幅度比代替自然感。 |
| V3-06 动效触发 | 小图标为固定首帧PNG，hover/focus后src及像素不变且排除动画调度。Logo循环、右图0→12后保持；hover/focus都解除后12→0且有中间帧，不立即跳回；提前离开、回程中重入从当前位置连续换向。暂停立即清零，主题卡推近只在hover/focus期间。 |
| V3-07 减少动态与焦点 | 系统reduce优先，审核reduce、真实window.blur、弹窗打开均暂停；重新聚焦可继续，键鼠模式切换无缓存焦点残留。独立document.hidden无法真实触发时保留未执行，不能伪造通过。 |
| V3-08 七入口流程 | 创建作品及题材打开真正可操作向导；默认不限/不限/全部，题材完整预选频道/长篇/题材/四标签组且每次打开重置。单选模板、过滤、频道/题材联动、20标签上限及详情Esc分层与真实生产纯函数比对。七卡Enter/Space可用，向导Tab循环、取消回焦；三个副入口聚焦输入框。 |
| V3-09 草稿与发送 | 向导取消不改草稿；确定定位段与选中prompt按真实composeWizardDraft拼贴，非空先确认替换，修改定位/模板后撤销确认。三个副入口直接填入模板，非空原文保留、同模板不重复添加、聚焦/高度更新；无模型发送禁用，不自动发送或持久化。 |
| V3-10 短窗及缩放 | 560×520与320×420、200%缩放等效布局；欢迎区七卡pointer/键盘可达；composer停靠。向导取消回入口，三模板聚焦composer；双主题窄/短真实浏览器窗口下向导定位/模板/确定按钮及详情可滚动可达，无横向溢出。 |
| V3-11 对比与视觉 | 实测两主题正文/辅助文字≥4.5:1；主题标题在背景图最亮可能区域经遮罩后≥4.5:1，检查实际图像与遮罩，不仅测CSS纯背景。宽/窄/短窗截图目视无溢出遮挡，主题图主体裁切合理。 |
| V3-12 范围与证据 | 仅设计目录；归档排除遍历；源码/资产哈希绑定当前v3。凭据格式扫描只输出计数、无内容。结果如实区分通过/失败/未执行，未实际运行的产品验证不标通过。 |

实现前由独立代理先审核方案，再审核上述用例。审美、图像主体与自然烟不能只以自动断言代替人工查看。
