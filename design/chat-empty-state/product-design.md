本版以最新用户要求覆盖旧版：四功能卡同尺寸、彩色静态小图标、灰度半透明右图、三题材图。右图保留0↔12悬停展开/倒放，Logo烟动画保留。v3.3进一步接入可操作的创作向导、题材定位预选和三类提示词填入，详见 [本轮修订记录](./revision-v3.3.md)。

## 1. 范围与空态守卫

仅重设计AI面板纯净空态。正式实施仍复用真实 `ChatPanel.tsx` 与 `components/chat/*`，不能将此HTML导入安装版。

欢迎区出现必须满足：消息加载已完成、消息数为零，且没有生成/运行、creatingNovel建书、待答问题、待批准计划、抽卡占槽、待确认请求、任何待发/暂停队列、执行恢复或错误。加载与错误沿用对应状态；不能只判断messages.length。

首条消息出现后欢迎区退出；同一个真实composer继续保留DOM、焦点、引用chip、输入法组合、撤销和草稿。不能为空态复制一份composer。

## 2. 布局与视觉

保留44px空顶栏。下面为可滚动欢迎区与不收缩的底部composer。欢迎区在剩余空间居中，内容过高则从顶部开始滚动；全部七张卡始终可达，composer不被卡片覆盖。

卡片组和composer共享最大800px宽度及水平留白，两侧实际边缘一致。宽度≥480px：第一排创建作品/新角色，第二排新世界观/新场景，四卡完全同尺寸；第三排仙侠/历史/科幻三卡。<480px全部改为单列，四卡保持统一高度，不为强塞首屏缩回小按钮。

| 元素 | 设计规格 |
| --- | --- |
| 欢迎头部 | 原香炉Logo约88px，标题“今天，想写点什么？”26px普通字重，辅助句“让一个念头，长成一个故事。” |
| 四张创作卡 | 创建作品、新角色、新世界观、新场景；两等列，统一114px高、26px图标、15px标题及相同右图尺寸规则 |
| 新增副标题 | 世界观“构建故事中的天地”；场景“让每一幕跃然眼前” |

| 四卡内容 | 图标/标题/副标题同一左边缘；右侧专属层叠插画，卡片裁切插画但不遮文案 |
| 创建作品 | 单色笔尖主题图标；右侧只有插画，没有箭头 |

四创作卡的基础表面、边框及hover表面一致，延续宣纸/玄墨现有主题。底部三主题图卡属于另一视觉层级，图像铺满，不受“四卡统一纯色背景”约束。图标每枚仅一种实色，但四图标各自不同：作品琥珀、角色紫、世界青绿、场景蓝。右侧背景插画低亮、半透明：玄墨为灰度100%/亮度62%/不透明度50%；宣纸在灰度后叠加50%sepia，得到贴近纸色的暖灰黄，所有动画帧共用这一滤镜。无玻璃模糊、厚重3D或大面积发光。

Logo玄墨使用#8d8984，显著低于v2的#d0d0d0；宣纸使用#b6a47c暖黄灰，接近纸色。原品牌路径与炉身保留。最终实际颜色/帧规格见assets/manifest.json。非品牌正文/辅助文字目标对比度至少4.5:1；题材卡的左侧深色遮罩承载文字，右侧逐渐变浅以保留主题细节。文案限制在左侧安全区域，窄卡允许自然换行。

## 3. 七个入口的动作契约

| 入口 | 正式产品意图 | HTML审核稿 |
| --- | --- | --- |
| 创建作品 | 打开现有CreateNovelDialog；准备新会话草稿，不自动发送，首次发送前落库 | 打开可操作向导，默认不限频道/不限篇幅/全部题材；确定后填入输入框 |
| 新角色 | 填入角色模板提示词，作者编辑后发送，由原AI流程处理 | 直接填入【角色】提示词并聚焦输入框 |
| 新世界观 | 填入世界观模板提示词，作者编辑后发送 | 直接填入【世界观】提示词并聚焦输入框 |
| 新场景 | 填入场景模板提示词，作者编辑后发送 | 直接填入【场景】提示词并聚焦输入框 |
| 仙侠 | 打开同一向导并预选对应频道/篇幅/题材/标签，可继续修改 | 男频、长篇、仙侠；古典仙侠/修仙界/热血/升级流 |
| 历史 | 同上 | 男频、长篇、历史；架空历史/古代/正剧/权谋 |
| 科幻 | 同上 | 男频、长篇、科幻；星际文明/星际/烧脑/经营 |

三个题材的男频预选来自当前分类法：仙侠、历史、科幻属于男频题材；作者仍可在向导中调整频道。向导字段、联动、过滤和拼贴依据真实 `CreateNovelDialog.tsx` 与 `src/lib/creation-wizard/{taxonomy,filter,compose,position}.ts`；401条预置模板按源码原顺序完整复制到本地离线数据，来源与哈希记录在wizard-data.js metadata中。

向导包含频道、篇幅、题材、子类/背景/风格/情节四标签组，以及主题/世界观/角色/剧情四环节模板。每环节单选，双击查看完整详情；频道/题材变化清理非法子类、风格及不可见模板。最多20个标签。确定按现有composeWizardDraft的定位段与四环节顺序拼贴；已有草稿时先提示，再由“仍要替换”覆盖，定位或模板变化撤销这次确认。取消、关闭和Escape不修改草稿；详情Escape只退出详情。

向导在短窗中保留固定头部与底部操作，分类、环节侧栏和模板列表各自滚动；真实视口高度≤650px时分类区最多占20%，模板区至少可完整展示一张卡片。窄窗已选摘要最多两行，悬停可查看全文，避免长模板标题挤压模板列表。

三提示词模板分别覆盖角色的身份/外貌/性格/关系/成长，世界观的时代/规则/势力/历史/冲突，场景的地点/空间/感官/人物物件/剧情作用。空草稿直接填入，非空草稿原文后追加两个换行与模板，同一完整模板不重复追加。保留作者编辑权，聚焦输入框并同步高度，不自动发送。

无模型不阻止打开向导或准备提示词，发送仍禁用。HTML不连接模型、不落库、不伪造创建成功。正式接入仍复用真实ChatPanel/composer及CreateNovelDialog，作品归属、新会话、模型门控和发送/停止沿原产品流程；此次只验证HTML交互。

## 4. 动画与资产

真实烟气参考和设计推论分开记录于revision-v3.md。Logo用原烟形的局部波包替换v2的整段往返拉伸；波包从根部附近上行，中上段弯曲，顶端减弱，炉口与炉身锁定。它是风格化品牌动画，不是物理仿真。

| 资产 | 规格 | 动作 |
| --- | --- | --- |
| Logo | 64帧/16fps/4秒，192px精灵单元 | 错时局部卷曲上行，首帧保留源轮廓，循环不倒放 |
| 四小图标 | 双主题原图标首帧PNG，每枚一种实色，显示26px | 固定图片，不进入动画调度 |
| 四右侧插画 | 原素材各24帧/20fps、192px单元，灰度半透明呈现；交互只使用0–12帧，单程约0.6秒 | 移入从0展开至12（主体最展开位置）并保持；移开由当前帧倒放回0 |
| 三题材图 | 内置imagegen分别生成、每张1942×809、本地PNG | 整卡满铺，hover/focus轻微推近；不冒称生成视频帧 |

小图标使用固定PNG，悬停与键盘聚焦不变帧。Logo独立hover/focus触发循环；创作卡整面hover/focus使右图展开。右图以0与中间峰值帧为目标：hover或focus-visible任一有效即展开，两者都解除才倒放收起；展开尚未结束便移开、收起中再次移入，均从当前位置换向，无首帧/中间帧跳切。方向切换前结算前一方向经过的时间，停在目标位置后不循环。系统减少动态优先、审核减少动态、真实失焦/隐藏、说明弹窗及创作向导均立即清零进度和时钟，并停止题材推近；暂停解除且仍满足触发条件时可重新展开。

主题图是原创生成的风格化背景，历史卡不作为特定朝代建筑史实。生成方式、实际完整提示词、保存路径、像素尺寸及SHA-256见 [image-prompts-v3.md](./image-prompts-v3.md)。原生SVG图标与右侧插画由本地代码生成，品牌源图不外传。
