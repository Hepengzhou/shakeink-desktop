# 版本与 GitHub Star UI 设计

日期：2026-10-13。可视稿：`index.html`，仅新增区域示意，不能导入正式工作台。

## 设置关于我们

保持既有 880×680 上限的左右设置窗；版本、反馈、文档后三条之后，最后行采用 primary 8% 混合背景、左侧 3px primary 标线、16px描边星标、加粗标题与两行辅助说明。右侧保留轮廓按钮，行内允许说明换行。主题沿用宣纸/玄墨实际 token，Tab 焦点可见。

## 欢迎页

保持 Logo、欢迎标题、真实笔名与创作说明，正文最末新增一块 12px 圆角轻背景邀请，13px正文，轮廓 Star 按钮。邀请辅助说明为11px。主“开始创作”继续在独立 footer 居中，且尺寸/焦点/完成语义保持。小高度窗口滚动正文，按钮可滚动抵达，禁止横向溢出。

## 独立关于

Windows 独立窗口扩大为 440×380，保留系统标题栏和受限渲染器；中间实际版本，下方一条温和邀请及链接。使用真实主题的明暗配色，系统缩放下正文可滚动。macOS 保留原生 About 外观，其 credits 区使用系统字体居中段落及可点击 GitHub 链接，最终布局由 AppKit 决定；HTML原型不充当macOS原生证据。

三个入口用不同文案，同一目标。不显示星数、不改变“已支持”状态；错误可访问、重试清晰，不用闪烁/强动画抢占主操作。
