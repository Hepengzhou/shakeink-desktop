# 版本与 GitHub Star 产品文档

依据：本轮用户目标、AGENTS.md 与 implementation-boundaries.md。日期：2026-10-13。

## 目标与行为

1. 发布标识为 `0.10-alpha`；包元数据为 `0.10.0-alpha`，设置关于与系统关于显示同一实际版本的用户格式。
2. 设置 → 关于我们：最后一行显示“喜欢玄印写作？”、“在 GitHub 点亮一颗 Star，让更多创作者遇见玄印。”与按钮“去 GitHub 点亮 Star”。整行突出显示。
3. 引导完成欢迎页：正文后增加“愿玄印陪你写下更多灵感。如果喜欢，欢迎用一颗 Star 支持我们。”与按钮“给玄印一颗 Star”。原“开始创作”为主按钮，点击 Star 不退出欢迎页，不改引导完成状态。
4. 独立关于：名称/实际版本/定位/许可证后增加“你的每一颗 Star，都是玄印继续打磨的动力。”与“在 GitHub 支持玄印”。Windows 为独立系统窗口，macOS 为原生面板底部 Credits.html 链接。

三个入口打开 `https://github.com/mySingleLive/xaanink-desktop`，使用系统默认浏览器。文案提示“将在浏览器打开 GitHub，点击仓库右上角 Star 即可支持。”；无强制支持、无自动访问、无支持完成标识。React 两入口与 Windows 关于的浏览器打开失败可再次点击并显示可理解的错误；macOS 原生链接的打开与失败由 AppKit/系统浏览器管理，不能承诺应用内重试提示。用户可直接开始创作。

## 验收

版本元数据同步；三个入口位置、顺序和文案准确；设置最后行显著但保持左右；鼠标/键盘操作正常；重复点击和失败重试不会改变业务数据；引导完成前不展示邀请，完成后展示；开始创作与退出焦点正常；双主题及小窗口可用；实际 Windows Electron、构建及完整现有回归据实记录；macOS 原生只能在真实 macOS 安装包验收。
