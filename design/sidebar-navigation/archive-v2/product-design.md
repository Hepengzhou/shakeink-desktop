# 左侧导航产品设计 v2

日期：2026-10-13。第二项产物。依据 [调研](research.md) 和本次用户要求；状态：等待本次 HTML 审核，不代表代码或产品测试通过。

最新修订：根据用户提供的 Codex“新聊天 / 你的 dot”截图，把创建入口由 44px 降至 32px，间距由 6px 降至 4px，文字由 13px 调至 14px，采用 20px 行高、500 字重。图标与文字保持垂直居中，左右边距和图文间距明确；这是参考截图比例后为本产品选择的逻辑尺寸，不声明 Codex 的实际样式值。

## 视觉规格

| 区域 | 规格 | 交互 |
| --- | --- | --- |
| 桌面控制栏 | 沿用 44px 和原生安全区 | 原后退、前进、收起保持 |
| 创建入口 | 每行 32px、间距 4px；容器左右 8px、上下 8px；按钮左右 12px、图文间距 10px、圆角 6px；文字 14px/20px、字重 500；图标与文字垂直居中 | 创建作品调用原向导；创建对话调用原 store；当前新对话的选中态规则保持 |
| 创建作品图标 | Lucide NotebookPen，18px、线宽 1.7 | 随现有普通/悬停颜色，不额外加底色或装饰 |
| 创建对话图标 | Lucide MessageCircle，18px、线宽 1.7 | 选中时随文字使用 primary |
| 作品阁标题 | 13px、现有衬线字体，左右 12px、上 10px/下 6px | 保持既有名称 |
| 业务树 | 28px 行高、每级缩进 14px、现有图标和选中态 | 作品、设定、世界、角色、场景、正文、对话等原操作保持 |
| 底部用户区 | 72px 高（含分割线）；左右 10px；按钮 52px、左右 8px；头像 32px、图文间距 10px | 整行打开原账号菜单；用户名 13px、邮箱 11px，不新增提示文案 |
| 用户文本 | 占据剩余宽度，单/双行随真实资料 | 姓名、邮箱都适用渐隐；完整姓名和邮箱保留在可访问名称/提示中 |

所有几何为 100% zoom 的 CSS px，随既有应用缩放运行；顶部原生 caption 换算由原组件负责。树区为唯一纵向滚动区域；创建入口和底部用户区不被挤小、不随树滚走。短窗时允许树区变短。默认栏宽 260px，沿用实际 200–420px 范围。

## 名称渐隐

覆盖：两个创建入口、所有 TreeNode 标签、独立 GlobalSceneTree 的场景名、不可用作品标题、底部姓名/邮箱及账户菜单头部姓名/邮箱。分组计数若当前是标签字符串的一部分仍随文字显示；独立的主角标记、状态点、操作按钮保持固定占位。

与 ContentTabs 一致：单行、不换行、无省略号；仅在 `scrollWidth > clientWidth + 1` 时启用末端 24px 的 `linear-gradient(to right, #000 calc(100% - 24px), transparent)`。未溢出文字完全不遮罩，不能常驻渐隐导致短名称变淡。栏宽、标题改名、菜单操作区占位、字号/zoom、字体加载和树节点挂载变化后重新测量。保持原完整字符串，不通过截断字符串实现。

完整标题通过原悬停卡和文字区域的原生 title 可查看；不替换已有“可拖拽到对话输入框引用”等帮助。行/可聚焦节点的可访问名称保留完整标题。图标、操作按钮和独立徽标不进入遮罩。账户邮箱依原真实数据展示，缺失时不添加示例值。

## 入口调整

“属性”不再出现在左导航的设定列表。不删除原属性数据、编辑/引用能力或已打开的 AttributesPanel，不新增另一个导航替代入口。

“情景试验场”变为与“物品”同级的单行入口，保留 FlaskConical 图标，去掉展开箭头、折叠状态、子树和树内“暂无试验场”提示。当前激活的 scenario Tab 属于此作品时，此入口使用原导航选中态。

点击文字/整行或 Enter、空格打开标题为“情景试验场”的管理弹窗。弹窗展示此作品的既有试验场列表；可打开原详情、创建、重命名和删除。导航行右侧原“+”仍可直接创建，鼠标悬停或键盘焦点进入时可见，点击不会同时打开列表。

弹窗采用原 Dialog 的主题、遮罩、尺寸与焦点管理：最大宽度 448px，视口边距至少 16px；列表在可用高度内滚动。顶部标明所属作品，保留“新建情景试验场”按钮。每项 52px 左右，名称可换行、提供完整标题，右侧原更多菜单含重命名/删除。空列表显示“暂无试验场”，提供新建；加载中显示加载状态；失败显示实际错误及重试，不能作为空列表展示。

打开详情时通过原 tabs store/场景离开门控激活同一个详情 Tab，成功后关闭列表；激活被拒绝或失败时保持列表并给出实际反馈。不创建新业务面板类型。创建弹窗、重命名或删除确认与管理弹窗互斥显示。由导航“+”直达创建时，取消/关闭返回启动“+”；由管理列表进入创建时，取消回列表“新建”按钮；列表内改名/删除取消回原记录，记录不存在时回“新建”按钮。创建成功打开既有详情；重命名同步标题后回列表原记录；删除成功刷新管理列表并沿用原 closeTab，焦点回列表“新建”按钮。Escape/关闭/点击遮罩退出列表，返回启动入口；试验场记录不进入导航树。HTML 仅演示此交互结构，不执行真实接口或删除。

## HTML 审核范围

入口 [index.html](index.html)。默认展示玄墨、260px 栏宽；可切宣纸，切 200/260/420px，切 900/640/500px 高度，以及普通、长名称、空作品、加载、错误状态。审核工具和尺寸说明放在导航之外。

使用明确合成示例，展示作品/角色徽标/世界/场景/对话，以及姓名和邮箱的长名称渐隐。右侧放同 24px 的 Tabs 标题示意，便于直接比较。可点击展开其他分组、选中业务项、滚动、打开账户菜单和情景试验场管理弹窗。创建入口仅提示原动作，原型不会创建实际作品或对话。
