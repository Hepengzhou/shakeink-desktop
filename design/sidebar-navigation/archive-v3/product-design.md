# 左侧导航产品设计 v3

日期：2026-10-13。第二项产物。依据 [调研](research.md) 和本次用户要求；状态：等待本次 HTML 审核，不代表代码或产品测试通过。

最新修订：根据用户提供的 Codex“新聊天 / 你的 dot”截图，把创建入口由 44px 降至 32px，间距由 6px 降至 4px，文字由 13px 调至 14px，采用 20px 行高、500 字重。图标与文字保持垂直居中，左右边距和图文间距明确；这是参考截图比例后为本产品选择的逻辑尺寸，不声明 Codex 的实际样式值。

v3 新要求覆盖 v2：第二入口名称为“新对话”、图标为附图对应的 MessageCirclePlus；场景取消导航内展开内容；“作品阁”改为作品/设定/角色/正文/对话五项分类 Tabs。此前的尺寸、底部用户区、属性移除、渐隐及情景试验场要求继续执行。

| 区域 | 规格 | 交互 |
| --- | --- | --- |

| 创建入口 | 每行 32px、间距 4px；容器左右 8px、上下 8px；按钮左右 12px、图文间距 10px、圆角 6px；文字 14px/20px、字重 500；图标与文字垂直居中 | 创建作品调用原向导；创建对话调用原 store；当前新对话的选中态规则保持 |

| 分类 Tabs | 作品、设定、角色、正文、对话五项等宽单行；外层高 36px，左右 margin 8px，上 4px/下 8px；内 padding 3px/细边框，间距 2px；选项高 28px、字号 12px/18px、小圆角 | 默认作品；选中中性亮底/细边，非选中弱文字；200px 也完整显示五项，无横向滚动 |
| 业务树 | 28px 行高、每级缩进 14px、现有图标和选中态 | 作品、设定、世界、角色、场景、正文、对话等原操作保持 |
| 底部用户区 | 72px 高（含分割线）；左右 10px；按钮 52px、左右 8px；头像 32px、图文间距 10px | 整行打开原账号菜单；用户名 13px、邮箱 11px，不新增提示文案 |

所有几何为 100% zoom 的 CSS px，随既有应用缩放运行；顶部原生 caption 换算由原组件负责。树区为唯一纵向滚动区域；创建入口和底部用户区不被挤小、不随树滚走。短窗时允许树区变短。默认栏宽 260px，沿用实际 200–420px 范围。

## 名称渐隐

覆盖：两个创建入口、所有 TreeNode 标签、四个分类中的作品分组标题、不可用作品标题、底部姓名/邮箱及账户菜单头部姓名/邮箱。五个 Tabs 标题完整显示；如因字号变化真的溢出，仍采用同种条件渐隐和完整可访问名称。场景已无导航子项，右侧场景目录外观不属于本次修改。分组计数若当前是标签字符串的一部分仍随文字显示；独立身份标记、状态点、操作按钮保持固定占位。

与 ContentTabs 一致：单行、不换行、无省略号；仅在 `scrollWidth > clientWidth + 1` 时启用末端 24px 的 `linear-gradient(to right, #000 calc(100% - 24px), transparent)`。未溢出文字完全不遮罩，不能常驻渐隐导致短名称变淡。栏宽、标题改名、菜单操作区占位、字号/zoom、字体加载和树节点挂载变化后重新测量。保持原完整字符串，不通过截断字符串实现。

完整标题通过原悬停卡和文字区域的原生 title 可查看；不替换已有“可拖拽到对话输入框引用”等帮助。行/可聚焦节点的可访问名称保留完整标题。图标、操作按钮和独立徽标不进入遮罩。账户邮箱依原真实数据展示，缺失时不添加示例值。

## 入口调整

“新对话”使用用户附图的圆形气泡内加号图标，替换 v2 的空心气泡，保留原新对话动作和选中态判断，不因分类选择重新创建会话。

“场景”与“物品”一样是单行入口，不带展开箭头、子场景或树内暂无场景提示。点击/Enter/空格复用 openAllScenes 打开当前作品的真实场景面板；当前 scenes/scene/scene-image 属于该作品时可使用原选中态。子场景管理、引用和层级树仍在原场景面板内使用。

“属性”不再出现在左导航的设定列表。不删除原属性数据、编辑/引用能力或已打开的 AttributesPanel，不新增另一个导航替代入口。

“情景试验场”变为与“物品”同级的单行入口，保留 FlaskConical 图标，去掉展开箭头、折叠状态、子树和树内“暂无试验场”提示。当前激活的 scenario Tab 属于此作品时，此入口使用原导航选中态。

点击文字/整行或 Enter、空格打开标题为“情景试验场”的管理弹窗。弹窗展示此作品的既有试验场列表；可打开原详情、创建、重命名和删除。导航行右侧原“+”仍可直接创建，鼠标悬停或键盘焦点进入时可见，点击不会同时打开列表。

弹窗采用原 Dialog 的主题、遮罩、尺寸与焦点管理：最大宽度 448px，视口边距至少 16px；列表在可用高度内滚动。顶部标明所属作品，保留“新建情景试验场”按钮。每项 52px 左右，名称可换行、提供完整标题，右侧原更多菜单含重命名/删除。空列表显示“暂无试验场”，提供新建；加载中显示加载状态；失败显示实际错误及重试，不能作为空列表展示。

打开详情时通过原 tabs store/场景离开门控激活同一个详情 Tab，成功后关闭列表；激活被拒绝或失败时保持列表并给出实际反馈。不创建新业务面板类型。创建弹窗、重命名或删除确认与管理弹窗互斥显示。由导航“+”直达创建时，取消/关闭返回启动“+”；由管理列表进入创建时，取消回列表“新建”按钮；列表内改名/删除取消回原记录，记录不存在时回“新建”按钮。创建成功打开既有详情；重命名同步标题后回列表原记录；删除成功刷新管理列表并沿用原 closeTab，焦点回列表“新建”按钮。Escape/关闭/点击遮罩退出列表，返回启动入口；试验场记录不进入导航树。HTML 仅演示此交互结构，不执行真实接口或删除。

## 五项分类与切换

| Tab | 下方显示内容 | 归属与层级 |
| --- | --- | --- |
| 作品 | 所有作品及各自完整业务导航树；保留原作品操作和未建档指引会话 | 沿用原作品展开层级，属性入口移除，场景/试验场为单行 |
| 设定 | 所有作品“设定”目录下的主题、文风、世界观/世界、金手指、伏笔、爽点/泪点等现有项目 | 每个作品名作不可点击分组标题，直接展示设定目录下条目，世界保持原层级；没有角色、正文、场景等项 |
| 角色 | 所有作品的角色名字列表，含正式角色和伏笔角色，保留主/配/反/伏笔等身份辨识 | 按作品分组，平铺人物；不再显示“角色→主角/配角/反派”折叠目录 |
| 正文 | 各作品的真实卷和章节正文列表 | 按作品分组，保留卷→章折叠层级与章节状态/原操作，不混入大纲或规划入口；作品标题右侧独立“正文导航功能菜单”保留原整书操作 |
| 对话 | 各作品的历史会话列表 | 按作品分组，直接列会话；未绑定作品的会话放“小说创作指引”分组，不混入其他业务项 |

各分类覆盖全部可读取作品，不被作品 Tab 的作品折叠状态限制。分类内的作品名只提供归属，不打开其他业务，独立菜单仍可操作。正文标题右侧复用原 OutlineTreeMenu(kind=content)，保留添加卷、整书导出和删除全部卷章等已有动作；卷章为空时仍可添加卷，空态明确为“暂无正文”，不出现“暂无大纲，去生成”或跳转大纲。其他卷章菜单、草稿/导出和删除确认仍用原真实组件。

每个作品没有目标记录时展示明确的“暂无角色/暂无正文/暂无对话”；角色的正式人物和伏笔人物查询分别显示加载/错误，只有两者成功且总数为0才显示暂无角色。设定固定入口保持原可用状态，世界列表独立处理空/失败。暂不可用作品在作品视图使用原状态卡，在分类中标明所属作品与不可用说明，不能假称无记录。分类内单个作品加载失败只影响自己的区域，其他已读取项目仍可用。

切换 Tabs 只改变左导航内容，不打开/关闭右侧内容 Tab、不触发发送、不重挂载编辑器或改变对话草稿。点击条目仍调用原真实业务动作、相同实体 ID、相同场景离开门控。右侧激活项不在当前分类时，不自动切分类。

鼠标点击立即切换。Tabs 用 role=tablist/tab/tabpanel；只有当前 Tab 处于键盘 Tab 顺序。左右方向键循环切换并聚焦，Home/End 到首/末项，Enter/空格可激活。切换焦点留在选项，不跳到列表第一项；Tab 可继续进入下方操作节点。每个分类各自保留当前会话内的滚动位置和可折叠目录状态，初次滚动从顶部开始；切回作品时保持原展开状态和位置。更换账户/目录或移除作品时清理失效状态，不新增跨重启的偏好。

## HTML 审核范围

入口 [index.html](index.html)。默认展示玄墨、260px 栏宽；可切宣纸，切 200/260/420px，切 900/640/500px 高度，以及普通、长名称、空作品、加载、错误状态。审核工具和尺寸说明放在导航之外。

使用两个合成作品和未建档指引会话，展示五项跨作品分类切换；可切普通、长名称、分类空列表、伏笔角色部分加载失败、空作品、加载、错误状态。伏笔失败示意保留同作品正式角色和另一个作品的角色，不当作暂无角色；重试恢复合成列表。右侧放同 24px 的 Tabs 标题示意，便于直接比较。可切分类、折叠目录、选中条目、滚动、打开账户菜单和情景试验场管理弹窗，点击场景提示打开原场景面板。创建入口、正文菜单只提示原动作，原型不会创建实际作品/对话或执行真实导出/删除。v2 原型和报告保存在 archive-v2/。
