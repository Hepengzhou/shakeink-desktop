# AI 对话标题：渐变淡出与大模型短标题 产品设计

日期：2026-10-16。依据调研 `docs/209-chat-title-research.md`。

## 背景与问题

1. AI 对话区域顶部标题栏目前用 `truncate`（尾部省略号）截断长标题，与左侧导航栏条目「尾部 24px 渐变淡出」的长文本处理不一致，同一界面两种截断语言。
2. 会话标题当前是「首条用户消息去 @引用负载后截断 50 字」（`src/lib/services/chat-turn.ts:194`），冗长、截半句、无概括性。Codex 等同类产品会在首轮对话后由大模型后台总结一句短标题并替换，用户无需手工命名。

## 产品目标

- **G1（视觉一致）**：AI 对话顶栏标题文字过长时，以与左侧导航栏条目完全一致的渐变淡出形式截断（尾部 24px 线性透明遮罩、不出省略号、仅真实溢出时生效、悬停可见完整标题）。
- **G2（自动短标题）**：会话有实质内容后，后台用大模型把对话总结成一句有总结性、代表性的简短话语，替换为该会话的正式标题：
  - 长度：中文一般不超过 15 个汉字（最好不超过 12 个）；英文或其他语言为类似长度（约不超过 8 个单词）。
  - 后台异步执行：不阻塞发送/生成/界面交互，不弹任何对话框，失败静默保留原标题。
  - 生成完成后顶栏与左侧导航栏中的标题一并更新为新标题（类似 Codex 的标题替换体验）。

## 用户可见行为

| 场景 | 行为 |
| --- | --- |
| 顶栏标题短 | 完整显示，无遮罩（与侧栏短条目一致） |
| 顶栏标题长 | 尾部渐变淡出，悬停显示完整标题 tooltip；窗口/面板宽度变化时实时重新判定 |
| 空会话引导页 | 顶栏不显示图标与标题文字（现状保留） |
| 新会话首轮助手回复完成 | 标题先保持「首条消息截断」，后台总结完成后自动替换为短标题；顶栏与侧栏同步 |
| 继续历史会话（标题仍是默认截断样式） | 回合完成后同样触发一次后台总结并替换 |
| 标题已是总结产物（不再等于默认截断） | 不再重复生成，标题稳定 |
| 未配置任何可用文本模型 | 静默跳过，标题保持原样，不弹「配置模型」提示、不打扰用户 |
| 生成失败（网络/模型异常/输出不可用） | 静默保留原标题；后续回合可再试 |

## 非目标（本次不做）

- 不提供用户手动重命名会话的 UI。
- 不为每条后续回合持续改写标题（标题生成一次、稳定）。
- 不改变标题字体、字号、颜色、高度等任何已批准 UI v0.13 视觉属性；不改动侧栏任何样式。
- 不引入新的设置项。

## 文案与内容要求

- 生成结果只取标题本身：去除引号/书名号/多余标点与换行；模型输出不可用时视为失败，不写入。
- 标题长度设硬上限兜底（30 字符），超出截断；正常应由提示词约束在 15 汉字/8 单词以内。
- 界面不出现「正在生成标题」等任何提示；替换是静默的。

## 验收标准对应

- G1：顶栏长标题渲染与侧栏条目同源同式（同一组件、同一样式类），浏览器实测 `data-overflow` 与 `mask-image` 渐变生效。
- G2：首轮完成后标题被替换为大模型短标题；无模型/失败时静默；全程不阻塞 UI、不弹窗；顶栏与侧栏同步刷新。
