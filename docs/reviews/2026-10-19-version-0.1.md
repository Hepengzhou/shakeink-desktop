# 项目版本 0.1

日期：2026-10-19。用户要求将项目版本从 `0.1.0-alpha` 改为 `0.1`。

## 技术方案

- `package.json`、lock 根及 lock 根包同步采用有效 SemVer `0.1.0`；界面通过现有 `displayAppVersion` 将该版本显示为 `0.1`。设置、bootstrap 和系统关于窗口继续使用现有公共格式函数。
- 格式函数只为 `0.1.0` 增加短显示，保留既有 alpha 版本和其它版本行为。
- README 当前版本同步为 `0.1`，保留开发版及验收范围说明。历史发布、安装包路径、哈希、日志和测试中的历史版本 fixture 不做全局替换。
- 保留开始工作时已有的未提交修改；不构建或发布新安装包，不触碰真实用户数据。

## 测试用例

1. 现有版本契约断言更新为 package/lock 三处 `0.1.0` 且 SemVer 有效；修改元数据前失败，修改后通过。
2. 现有格式回归增加 `displayAppVersion('0.1.0') === '0.1'`；保留 alpha、非零补丁、其它主版本和未知字符串覆盖。
3. 设置浏览器用例使用从当前 package 元数据派生的版本，断言实际设置显示 `0.1`。
4. 执行完整版本 unit/browser 用例和打包配置回归；在本机真实 Electron 上核对当前项目元数据与公共格式函数的版本。
