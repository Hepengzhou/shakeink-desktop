# 顶部消息框产品设计

日期：2026-10-12。状态：用户已批准第一版并授权继续实施。目标是让顶部消息框形成清晰、独立的实色浮层，让用户能快速识别消息类型、阅读内容并点击既有操作。

## 范围与用户体验

所有通过现有全局 Sonner 发出的顶部通知统一使用新样式，包括提示、成功、警告、错误、加载和一般消息。保留真实消息内容、描述、按钮文案与回调、计时长度、dismiss、promise、同 ID 状态更新、队列顺序、悬停／聚焦暂停与已有可访问性机制。没有业务操作的消息不增加操作按钮；不新增关闭按钮、分类标签、进度条、声音或强制确认。

在示例场景中，“已保留 1 项待核对草稿”显示蓝色提示图标、暖白或暖黑实色卡片与“查看草稿”按钮；点击后仍打开现有草稿界面。卡片内容及数量继续来自实际状态，设计页内的固定示例只是审核材料。

## 视觉规格

| 元素 | 拟议规格 |
| --- | --- |
| 定位 | 顶部居中，距 44 DIP 原生标题区底部 16px；实施按现有 `--desktop-caption-zoom` 计算标题区安全距离 |
| 宽度 | 标准 420px；上限为窗口宽度减 32px；不按消息长度抖动 |
| 卡片 | 12px 圆角、1px 细描边，垂直 14px／水平 16px 内边距；无背景图片、模糊或半透明填充 |
| 文字 | 正文 14px、行高 22px、字重 500；描述 13px／20px，文字颜色随主题；自然换行，不截断必要内容 |
| 图标 | 20px，32×32px 圆角底座，左侧固定位置；短消息垂直居中，多行时靠首行 |
| 操作 | 中性实色描边按钮，最小高度 32px，字号 13px；支持清晰 hover／focus-visible；长文本或窄窗口允许另起一行，保留按钮完整文案 |
| 层级 | 沿用 Sonner 层级与动画；纸色使用轻投影，墨色依靠提亮表面、细边及浮层投影 |

| 主题 | 卡片背景 | 正文 | 描述 | 描边 | 按钮背景／文字 |
| --- | --- | --- | --- | --- | --- |
| 宣纸 | `#fcf8ee` | `#2b251b` | `#74664f` | `#d8cba6` | `#f2ecdd`／`#2b251b` |
| 玄墨 | `#211c19` | `#ece7e1` | `#b5a99f` | `#4b4039` | `#322b25`／`#ece7e1` |

阴影：宣纸 `0 8px 24px -8px rgba(96,74,38,.18)`，玄墨 `0 8px 24px -8px rgba(0,0,0,.6)`。背景色 alpha 为 1；阴影可半透明，不影响卡片不透明要求。

| 类型 | 图标形状 | 宣纸图标／底座 | 玄墨图标／底座 |
| --- | --- | --- | --- |
| 提示 | 圆形 i | `#356caf`／`#e8eff8` | `#8ab6f4`／`#233449` |
| 成功 | 圆形勾 | `#397653`／`#e7f0e7` | `#89c59d`／`#24392c` |
| 警告 | 三角感叹号 | `#a36d18`／`#f5ead4` | `#edc070`／`#40331f` |
| 错误 | 八角叉 | `#b84b42`／`#f7e4df` | `#ef9992`／`#432a28` |
| 加载 | 旋转圆弧 | `#68778a`／`#eceef1` | `#b0bbc9`／`#2d323b` |
| 一般 | 沿用调用方，无图标时不制造类型 | 中性主题色 | 中性主题色 |

颜色与图标形状共同表达类型。正文／描述／操作文字对背景至少 4.5:1，信息图标对底座至少 3:1；保留 live region，消息弹出不夺取编辑器焦点。减少动态效果时取消装饰旋转／过渡，加载文案仍说明状态。

## HTML 审核稿

`design/toast-style/index.html` 是本地离线审核页。提供宣纸／玄墨切换、真实当前组件与拟议样式对照；拟议类型列表可逐一查看，支持短消息、有操作、长文描述、加载转成功及多消息队列演示。按钮只更新本页说明，不执行产品操作。页面明确标注设计示例。

审核要点：实色背景能完全遮住底层横纹；四类状态颜色明确；暖白／暖黑风格协调；卡片、图标及按钮尺寸合适；长文和窄窗口无裁切。用户批准第一版后，再进入代码实现。

## 实施与专项验收

拟修改 `src/components/ui/sonner.tsx`、`src/app/desktop.css`，必要时调整 `src/app/providers.tsx` 的外观参数。修正 `paper → light`、`ink → dark` 映射；样式只命中本通知组件。业务调用、工作台真实 React 组件和上游仓库保持既有实现。

批准后先形成技术方案并独立审核，再编写与独立审核测试用例；目标用例先失败、实现后通过，并做独立 code review。专项覆盖：两主题×所有类型的背景 alpha 和图标颜色／形状；操作 hover／focus／点击；长文本、窄窗口；加载同 ID 更新、消息堆叠、计时／暂停；标题区安全距离与 no-drag；主题切换后现有消息更新。真实 Windows Electron 使用隔离测试目录及零模型，检查真实组件和可达的草稿按钮场景。

只执行本次目标相关测试，不运行全量单元、集成、浏览器或回归测试。HTML 预览检查仅证明设计材料可用；macOS、安装包或其它未执行平台不记为通过。完成后在 `docs/requirements-traceability.json` 与 `docs/migration-map.json` 记录批准稿、实施文件、专项测试和真实证据。
