# 小说创作向导上下文回归用例

各项以真实函数、真实业务路径或实际 Windows Electron 运行结果验收；受控端点测试和实际 DeepSeek 调用单独记账。

| 编号 | 用例 | 预期 |
| --- | --- | --- |
| CC01 | 官方精确两型号的新建内置目录和认证目录补全 | 返回无容量时补1000000；供应商明确1048576优先；精确实时型号和认证权限另查 |
| CC02 | 已保存的官方文本 OpenAI 配置容量 0 | 两型号 localModelRecord 为 1000000，原配置及快照保持 0，授权身份不变 |
| CC03 | 明确配置 1048576 或 16384 | 使用明确值，不覆盖或放大 |
| CC04 | 未知型号、其他供应商、自定义、错误协议/IMAGE类别、HTTP、代理域名、非默认端口、凭据、查询、片段及不支持路径 | 保持原未知模型16000预算；许可HTTPS根路径、/v1、/v1/以及规范化默认443端口 |
| CC05 | 真实 chat.system、仙侠四类模板、完整97工具与初始按需工具 | 用原 estimateTokens/estimateToolTokens/manageConversationContext/assertPromptFits 证明旧0模型失败、修复后预算通过；保留16k和超限保护失败断言 |
| CC06 | 原向导确认与 composer 发送 | 首发真实请求型号与冻结任务型号一致；核对向导重建选择和重试快照行为 |
| CC07 | 实际官方 /models 和两指定型号首发 | 主进程系统密钥保护、真实 SDK / endpoint；失败诊断只记状态码和错误码 |
| CC08 | Windows Electron 从仙侠入口至正文 | 选择四类模板、确定、发送；真实简报、主题、世界、人物、剧情、大纲细纲、正文写入及必要审批，无生成失败或安全预算阻塞 |
| CC09 | 保存后关闭与重开 | 作品、会话、正文实际仍可读取，原安全/审批约束继续有效 |
| CC10 | 全量回归、类型检查、构建 | 记录所有实际结果与平台限制，已有失败不能算通过 |

先执行 CC01–05 失败用例，再实现容量修复。CC06–09 使用独立临时数据根与作品目录；仅读取当前已授权官方模型配置所需的加密凭据，不读取用户作品。目录选择可由测试提供空目录，此限制与真实模型调用分开注明。真实 Key、供应商原始响应、用户真实内容不写源码/日志/证据。
