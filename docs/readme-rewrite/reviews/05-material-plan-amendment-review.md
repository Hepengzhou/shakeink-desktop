## 1. 显式恢复已有演示库

**通过。** `launch-demo.mjs` 只接受默认形式或唯一显式参数 `--resume-demo`，不认识的参数直接拒绝。`workspace-guard.mjs` 的 `allowConfiguredModels` 默认 `false`，未带恢复参数时仍要求模型数量为零；恢复参数只放宽这一数量门。

其余防护保持：根必须是规范 `/private/tmp/shakeink-readme-*` 直接子目录，marker 为原创摄影用途，fixture 仍记录初始零模型且内容哈希与当前原创源一致；两本作品必须对应本次 catalog、目录路径和设备/inode；存在的 bootstrap 和根指针继续接受真实目录与身份核验。guard 完成以后才启动 Electron，没有通过恢复参数重写、复制或清空现有模型配置。

guard 仅读取模型数组并返回数量，不做含模型对象的深比较；启动和采集工具没有解密、打印、修改凭据或调用模型的代码。选项由此前的 `captureOnly` 改为含义准确的 `allowConfiguredModels`，避免把启动恢复误称为只读采集。采集仍只记录模型数量及窗口元数据。

该工具源码只能证明其自身没有发起模型调用，不能证明用户手动操作期间从未调用模型。因此公开说明使用“助手不为摄影调用模型”“内容为预先准备的原创演示文本”等精确表述；不要从数量检查推导“当前无 Key”或“所有历史均无调用”。制作记录已区分初始零模型与用户后续配置的两个模型，避免旧结论失真。
