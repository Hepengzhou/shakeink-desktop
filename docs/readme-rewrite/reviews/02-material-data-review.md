| P2 · 故事设定一致性 | `demo-content.ts:19`、`:29` 与 `:56` | 设定称陆照微每次读墨暂时失去“一种颜色”的辨识，第一章却写金色消失后“朱印、窗外的灯影，一齐变成了深浅不同的灰”，呈现全色觉消失。世界档案、人物能力和正文将作为不同截图公开，读者能直接看到不一致。 | 保留单色代价，并把正文局限于某一种色调的丢失；或统一设定为暂时失去辨色能力。选择一种后同步简介、世界、人物和正文。 |

## 通过的部分

- **题材与人物合理性**：仙侠中陆照微十九岁、十二岁起学艺、父亲三年前失踪相互兼容；裴慎四十一岁、十八年前为书办不存在年龄冲突。魂灯只辨生者气息与失踪者姓名重新出现属于悬疑谜面，没有直接宣称死者复生。历史穿越主角的纸张手艺、材料限制与信用代价明确，没有现代设备或无成本技术跃迁。
- **正文质量与虚构边界**：两本书各两章自然正文、其余章节明确为纲要；段落以动作、对话与线索推进，没有重复凑量。历史背景明确为原创故事环境，未把虚构案件当史实；角色、笔名和故事均为展示素材。
- **伏笔落点**：三条伏笔分别为已埋铜铃、已埋船号和计划中的旧印；触点引用均能在对应正文找到，脚本在创建前断言引用确实出现。旧印没有强行伪造已埋或已回收状态；铜铃的第二卷回收计划与第一卷调查、留证可共存。
- **生成器的初始隔离**：seed 要求新建、空、规范的 `/private/tmp/shakeink-readme-*`，拒绝符号链接别名及非空目录；只在其中创建 `data`、`book-0`、`book-1`，没有递归清理代码。`prisma` 是工作区上下文代理，由 `works.run(work.id)` 绑定实际隔离数据库，导入本身不连接作者默认数据库。
- **零模型与样稿标注**：从 `defaultState` 克隆，默认模型数组为空；邮箱为空、头像为空，只使用虚构笔名。fixture 和 marker 标记原创/README 用途，规划引用为“作者构思”。捕获报告明确不展示真实 AI 调用结果，A09 省略；后续 README 应采用“预先编写的原创演示内容，非应用内 AI 调用结果”等准确说明。
- **采集真实性**：`capture.mjs` 通过真实 UI 点击面板、主题和分屏，没有 DOM/CSS 替换或注入画面文字；修改的只是本次窗口 bounds。实际文件来自原生 `screencapture -l`，Sharp 只读取尺寸、哈希和分析左上像素，没有改写图片。Swift 只按本次进程 PID、窗口标题和 layer 0 只读选择窗口；找不到唯一窗口即失败。
- **未提前声称验收**：截图记录保留 `pending-independent-review`；红黄绿像素检测仅可作为采集预检，不能替代人工看图。报告 scope 区分 macOS 开发应用、安装包与 Windows 验收，符合宣传事实边界。
