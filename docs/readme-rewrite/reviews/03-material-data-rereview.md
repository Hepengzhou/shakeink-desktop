## 新拍摄方式符合本次授权边界

- **启动与操作分离**：`launch-demo.mjs` 仅以隔离根启动实际 Electron，记录本次进程 PID；没有 Playwright、点击、输入或网页脚本操作。UI 操作仍由用户选择的当前电脑工具执行。
- **截图来自原生窗口**：`capture-native.mjs` 只调用 Swift 窗口定位与获准的系统 `screencapture`。Swift 按 PID、真实窗口标题与 layer 0 选择唯一窗口，不会主动切换或操作窗口。
- **不修图掩盖问题**：Sharp 仅读取元数据和分析左上像素，最终图片通过原文件复制形成，没有绘制三按钮、拼贴、擦除警告或替换页面。三按钮像素预检失败时，原图留临时目录，脚本在复制到公开目录前退出。
- **没有提前宣布通过**：即使颜色预检通过，manifest 仍标记 `visualReview: pending`，并明确内容和告警需要独立看图。像素数量不能独立证明三个按钮无遮挡，也不能证明选景、清晰度或无警告。
- **正式产品边界保持**：工具只使用本次临时作品，未添加默认模型、真实 Key、模型请求或发行承诺。未以 macOS 开发应用截图替代 Windows 或安装包验收。

仅有一处非阻断注释残留：`window-id.swift:4` 仍提到已删除的 `capture.mjs`，可改成当前 `capture-native.mjs`/`launch-demo.mjs`，不影响窗口定位行为。
