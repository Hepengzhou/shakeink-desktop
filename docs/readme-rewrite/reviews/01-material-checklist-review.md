# README 素材准备清单独立审核

**结论：通过，可以进入素材制作。未发现阻断或高优先级问题。此结论不代表图片已经制作、素材已经验收，也不代替后续大纲及 README 的用户审核。**

## 范围与依据

完整阅读 [调研文档](../01-research.md)、[素材准备清单](../02-material-checklist.md)，并核对根 `README.md`、`package.json`、`electron-builder.config.cjs` 和 `docs/implementation-boundaries.md`。

本次核查计划的完整性、真实性约束、平台与发行表述、隐私隔离和阶段门。没有执行安装构建、启动应用、审查尚未产生的数据脚本或查看最终截图；调研中的外部网站访问记录不属于本次独立重访范围。具体业务字段和素材实际可用性须由制作后的独立审核核实。

## 低优先级建议

| 严重度 | 位置 | 具体问题 | 建议 |
| --- | --- | --- | --- |
| P3 · 表述澄清 | 素材清单第 57 行 | 同一“通过标准”同时用于清单审核与制作后审核，“所有必选图实际存在且逐图通过”在当前制作前阶段尚不适用，容易误读为清单审核已验证图片。 | 分开写为“清单准入：无阻断/高优先级问题，覆盖全部要求”及“素材验收：必选图片实际存在且逐图通过”。本报告已明确区分两者。 |
| P3 · 读者可见标注 | 素材清单 A09、第 33 行 | 人工样稿目前要求在素材说明标明；若最终图片被用于 AI 亮点，普通 README 读者未必会打开过程文档，仍可能误认为发生过真实模型调用。 | 若采用人工候选稿或草稿，在 README 对应图片附近也简短标注“原创演示稿，人工准备”，并按实际状态说明模型需自行配置；未调用模型的图片不要配生成成功类标题。 |

以上建议不阻止素材制作，建议在进入素材审核前落实。

## 下一阶段必须核实

1. 查看每张最终原生截图，确认三按钮、完整窗界、清晰度、真实内容、无报错警告及无隐私；仅检查尺寸或哈希不构成视觉验收。
2. 审查隔离数据脚本及实际服务读回结果，核对两部作品的章名、人物、时间线、伏笔与正文，不把本次宣传素材准备写成业务全量验收。
3. 核对每图来源、尺寸、哈希、主题和真实操作入口；构建或拍摄失败应保留真实记录，不能通过改界面、擦除提示或设计稿补图弥补。
4. 素材通过独立审核后再编排大纲；大纲通过独立审核及用户审核后才撰写根 README。
