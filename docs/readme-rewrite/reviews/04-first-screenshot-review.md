## 本轮工具调整

1. `workspace-guard.mjs:31–35` 仅检查模型数组类型和数量；默认 `captureOnly = false`，启动仍要求零模型。`capture-native.mjs:12` 明确选择只读采集模式，允许用户已手动配置的模型存在。源码中没有解密、打印模型对象或发起模型调用的代码，降低了此前深比较断言把配置对象带入错误输出的风险。manifest 只记录数量 2，不写供应商、型号或凭据。**本轮变更可通过静态审核**；本次未重新执行含用户配置的 guard，不能把静态检查写成运行期验证。
2. 采集仍只定位窗口并调用已获授权的 `screencapture`；未引入 Playwright、输入、点击、DOM/CSS 修改。Sharp 只读元数据/采样像素，发布文件通过 `copyFile` 保留原像素。未发现图像修饰或补画窗控。
3. `capture-native.mjs:43–55` 把原红黄绿硬判定改为共享指示条预检并保留人工验图门。**此调整合理**：颜色统计只能作诊断，灰色三按钮已在实际图中验证。该预检本身不能证明按钮存在或无警告，`nativeControlsVisualReview`、`visualReview` 继续写 `pending` 是正确行为；最终状态必须由逐图审核更新。
